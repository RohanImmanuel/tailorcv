01

From JD to Google Doc in five steps

Store your career once. TailorCV handles every application.

01

Store your career profile

Run tailorcv profile once to save your experience, projects, skills, and certifications. Stored locally at ~/.config/resume-tailor/ - never in the cloud.

02

Paste the job description

Run tailorcv generate, enter the company and role, then paste the JD directly in your terminal. Press Enter twice to continue.

03

GPT-5.5 tailors your resume

Your profile and JD are sent to GPT-5.5. The model scores your fit, identifies must-have requirements, and generates a truthful tailored resume - no invented experience, no inflated titles.

04

Your Google Docs template is filled

TailorCV copies your pre-formatted template and fills it with generated content - preserving all your fonts, spacing, tab stops, and bullet styles exactly as designed.

05

Get a direct link

A link to the finished Google Doc is printed in the terminal. Saved to your Drive as ResumeTailor / Company - Role - Resume.

02

Built for serious job applications

Not just keyword matching - TailorCV optimises for recruiter shortlisting.

🎯

Recruiter-first optimisation

Scores your JD fit, prioritises must-have requirements, and leads with your strongest matching evidence - not just ATS keywords.

🚫

Zero hallucination

Strict rules prevent invented metrics, inflated titles, missing skills being claimed, or adjacent experience presented as direct ownership.

🎨

Formatting preserved

Your Google Doc template formatting is never touched. Fonts, tab stops, bullet styles, and spacing carry over to every generated resume.

🔒

Your keys, your data

Profile data and API keys are stored locally at ~/.config/resume-tailor/ - never inside the project, never on any server.

📄

Custom template

Design your own resume template in Google Docs once. TailorCV copies and fills it on every generation using simple placeholder tags.

💻

Cross-platform

Works on Mac, Linux, and Windows. Pure Node.js with no native dependencies - install once, use anywhere.

One command to install

$ npm install -g tailorcv
GitHub → Read the docs
03

Four commands. That's it.

You need an OpenAI API key and a Google account.

tailorcv setup
Add your OpenAI key and connect Google Drive via OAuth. Run once.
tailorcv profile
Fill in your career profile - experience, skills, projects, education, certifications.
tailorcv generate
Paste a job description and get a tailored Google Doc resume in ~15 seconds.
tailorcv template
Reset your Google Docs template to the latest placeholder format.
04

Nothing leaves your machine except what you choose

No accounts. No analytics. No backend. Just you, OpenAI, and Google Drive.
